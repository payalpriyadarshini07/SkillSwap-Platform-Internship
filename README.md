\# SkillSwap Platform



A full-stack skill-sharing platform developed during my internship at Apticode2025.



SkillSwap is designed to connect users who want to learn new skills with users who can share their knowledge. The platform provides a structured environment for skill discovery, user interaction, and skill exchange.



\## Features



\- User registration and authentication

\- User profile management

\- Skill listing and management

\- Skill discovery

\- Skill-sharing functionality

\- User-to-user interaction

\- Full-stack frontend and backend architecture

\- REST API-based backend

\- MySQL database integration
